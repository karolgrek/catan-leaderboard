# Project Guidelines & Rules

## Terminal Command Execution & Permission Rules
- **Do not execute frequent ad-hoc terminal commands** that require manual confirmation prompts every few seconds.
- For reading, searching, or editing files, always use built-in tools (`view_file`, `replace_file_content`, `write_to_file`).
- When running terminal commands is necessary, first plan and outline what commands are needed and inform the user before running them, batching them whenever possible.
